Musodoro

An exploratory look at EEG beta-band power during Pomodoro study sessions.

Independent project, 2025

Code

overview

Musodoro streams brain activity from a Muse 2 headband while you study and shows how beta-band power changes across Pomodoro intervals. Beta power alone doesn't measure stress, so this is an exploration, not a stress detector.

what it does

  • Shows live band powers, updated every second, in a React dashboard.
  • Runs a short calibration (about 30 seconds) to set a personal beta threshold.
  • Shows an on-screen alert when relative beta power rises above that threshold.

how it's built

  • A Flask and Socket.IO backend reads the Muse 2 EEG stream over LSL (via BlueMuse).
  • Signal processing in Python: 1–45 Hz bandpass filtering, Welch power spectral density and band-power integration.
  • The threshold adapts to each user: the calibration mean plus 1.5 standard deviations.
