HashDecode

Paste an Ethereum transaction hash and get a plain-English explanation of what happened.

ETHGlobal hackathon, 2025

Live app Code

overview

Raw transaction hashes are unreadable. HashDecode takes one and explains what it actually did: token swaps, DeFi operations, NFT transfers and more.

what it does

  • Explains what the transaction did, which tokens and protocols were involved, and how much moved.
  • An expandable technical-details panel shows the raw on-chain data.
  • Validates input before calling any APIs.

how it's built

  • An Express backend fetches transaction data from the Blockscout API and uses OpenAI to write the explanation.
  • API endpoints: POST /translate, plus health and status checks.
  • A React front end with a responsive layout.
