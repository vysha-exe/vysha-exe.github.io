  1. RM

    Remit: Cross-Border Payments with On-Chain Settlement

    Team project · TypeScript, Next.js, Express, TronWeb, Coinbase Advanced Trade API

    UPenn Blockchain Hackathon, 2026

    Code

    A consumer-facing payment prototype: a Next.js front end and Express backend with live FX previews, transfer tracking and transaction history. Settlement runs as TRC-20 transfers on the TRON Nile testnet through TronWeb, with real testnet transaction IDs recorded. The Coinbase Advanced Trade API handles account retrieval and USDC purchase flows over CDP JWT authentication.

    Card data is kept to a minimum: the API stores only the last four digits, and expiry and CVV never reach the server. I split the technical and regulatory research across the team, coordinated the build under the deadline, and pitched the product. It's a testnet prototype, not a licensed or production payment service.

  4. KX

    Kinetix: Computer-Vision Physiotherapy Coach

    Team project · JavaScript, FastAPI, Oracle Cloud, OCI Generative AI

    Oracle HackTN, 2026

    Demo Code

    Patients practise their physical therapist's home exercises with live, on-camera form feedback, and the therapist reviews progress and approves AI-drafted plan changes. Pose tracking runs in the browser: 33 body landmarks become 26 joint angles, and a logistic-regression classifier trained on 1,700 physiotherapist-labeled reps flags common form errors.

    Oracle Cloud speech gives spoken coaching and Oracle Generative AI drafts session reports. I built backend components and the cloud integrations with my team.

  5. ATB

    Agentic Transfer Bench: Adapting Foundation Models Under Dataset Shift

    Team project · literature review and framework design

    Vanderbilt BrainHack, 2026 Conceptual

    Video

    A review of agentic ML pipelines, foundation-model adaptation under dataset shift, transfer learning and human-in-the-loop oversight, applied to physiological (PPG) data. From it I designed an orchestration framework that separates deterministic preprocessing from agent decisions and defines how to evaluate adaptation and generalization. It's a framework design, not an implemented system.
