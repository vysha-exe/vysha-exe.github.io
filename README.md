# vyshalini-website

Personal site of Vyshalini Rajendran. Plain HTML, CSS and JavaScript with no build step, served by GitHub Pages.

- `index.html`: about page
- `projects/index.html`: projects
- `research/index.html`: research
- `styles.css`, `script.js`: shared styles (black and green, with a light toggle) and behavior
- `assets/img/`: photo and thumbnails; see `assets/img/README.md` for file names

## Run locally

```
python -m http.server 8000
```

Then open http://localhost:8000.
