# Images

| File | Where it shows |
|---|---|
| `profile.jpg` | Photo on the about page (portrait, 4:5) |
| `projects/<name>-logo.svg/png` | Project logos (from each repo) on the project cards, and on the project page when there's no screenshot |
| `projects/sancus.jpg` | Screenshot at the top of the Sancus page |
| `projects/kinetix.jpg` | Picture at the top of the Kinetix page |
| `research/vflip3-poster.jpg` | vFLIP3 poster on the research page |

To give another project a screenshot, add it here and set `shot` for that project in the page generator (or swap the logo tile in that project's `index.html` for an `<img>`).
