# Images

Drop images here with these exact names. Until a file exists, the site shows a placeholder in its place.

| File | Where it shows |
|---|---|
| `profile.jpg` | Photo on the about page (portrait, about 4:5) |
| `projects/remit.png` | Remit thumbnail |
| `projects/sysflow.png` | SysFlow thumbnail |
| `projects/hashdecode.png` | HashDecode thumbnail |
| `projects/kinetix.png` | Kinetix thumbnail |
| `projects/agentic-transfer-bench.png` | Agentic Transfer Bench thumbnail |
| `research/vflip3.png` | vFLIP3 thumbnail |
| `research/neurostream.png` | NeuroStream thumbnail |
| `research/thinkneuro.png` | ThinkNeuro study thumbnail |

Thumbnails display at 4:3 and are cropped to fill, so a screenshot or poster figure around 800×600 works well.
To use a .jpg instead of .png, change the matching `src` in `projects/index.html` or `research/index.html`.
